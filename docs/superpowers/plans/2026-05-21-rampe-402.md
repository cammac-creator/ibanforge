# Rampe d'accès 402 — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Exposer le rail « packs de crédits » (carte via Stripe + bundles prépayés USDC) dans la réponse `HTTP 402`, aux côtés de la clé gratuite et du x402 déjà présents.

**Architecture:** Une fonction partagée `buildAccessRamp()` dans `src/middleware/enrich-402.ts` produit les blocs lisibles du corps 402. Les deux chemins d'enrichissement — Path 1 (corps `{}`/vide, le chemin de production) et Path 2 (corps avec `accepts`, filet de sécurité) — la fusionnent dans le corps **sans jamais altérer** le tableau `accepts` ni l'injection `outputSchema` (recette Bazaar verrouillée par les tests).

**Tech Stack:** TypeScript strict, Hono, vitest.

**Spec :** `docs/superpowers/specs/2026-05-21-rampe-402-design.md`

**Notes d'exécution :**
- Les tâches sont séquentielles : la Tâche 2 utilise `buildAccessRamp()` créée en Tâche 1.
- Tous les commits utilisent des `git add` à chemins explicites — ne jamais `git add -A` ni `.` (le fichier `POINT-SITUATION.html` non suivi à la racine doit rester non committé).
- Référence du corps 402 réel en production (vérifié le 2026-05-21) : `{ x402Version, error, message, accepts, free_tier, x402, documentation, llms }` — il manque `credit_packs`.

```ts
/**
 * Human- and agent-readable access ramp shared by both 402 enrichment paths.
 * Lists the three ways to call a paid endpoint: a free API key, prepaid
 * credit packs (card or USDC), and pay-per-call x402. The machine `accepts`
 * array is built separately and never lives here.

function buildAccessRamp(): Record<string, unknown> {
  return {
    message:
      'Authentication or payment required. Three ways in: a free API key ' +
      '(200 req/month), prepaid credit packs (card or USDC), or pay-per-call via x402.',
    free_tier: {
      description: '200 requests/month — no credit card, no subscription',
      signup: 'POST /v1/keys/generate with body {"email":"you@example.com"}',
      usage: 'Add header: Authorization: Bearer ifk_your_key_here',
    },
    credit_packs: {
      description: 'Prepaid credits — never expire, lower per-call cost than retail',
      pay_by_card: 'https://api.ibanforge.com/#pricing',
      pay_by_usdc: 'POST /v1/credits/buy/1k|5k|25k — list: GET /v1/credits/bundles',
      pricing: '1k = $5 · 5k = $20 (-20%) · 25k = $80 (-36%)',
    },
    x402: {
      description: 'Pay per call with USDC on Base L2 (machine-to-machine)',
      protocol_docs: 'https://x402.org',
      discovery: 'https://api.ibanforge.com/.well-known/x402',
      bazaar: 'https://api.cdp.coinbase.com/platform/v2/x402/discovery/resources',
    },
    documentation: 'https://ibanforge.com/docs',
    llms: 'https://api.ibanforge.com/llms.txt',
  };
}
```

Les valeurs de `free_tier` et `x402` sont **identiques** à celles du corps Path 1 actuel ; seul `message` est élargi et `credit_packs` est nouveau.

```ts
    if (text && text.trim() !== '' && text.trim() !== '{}') {
      let parsed: { accepts?: AcceptEntry[]; [key: string]: unknown };
      try {
        parsed = JSON.parse(text);
      } catch {
        return; // not JSON, leave alone

      if (!Array.isArray(parsed.accepts) || parsed.accepts.length === 0) return;
```
