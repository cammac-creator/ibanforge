  • monétisation · vérifié en prod

    Prix du batch corrigé (ton choix : dynamique)

    Avant : forfait $0.20 même pour 1 IBAN (100× trop). Maintenant : N×$0.002. Prouvé sur le live — 1 IBAN = $0.002, 100 = $0.20.

  • juridique · le plus sensible

    Disclaimer + périmètre sur chaque réponse compliance

    Un bloc meta dit désormais explicitement : screening au niveau banque (BIC8) seulement, pas le bénéficiaire, pas un produit AML réglementé — + les dates de fraîcheur des données. Évite un faux sentiment de sécurité.

  • découvrabilité

    Package MCP publié réaligné sur la vraie API

    Les schémas mentaient (bankName, risk_score à plat…) → corrigés. Tue le drift qui plombait le score Smithery/Glama.

  • exactitude données

    Score de risque dé-biaisé + données suisses

    Retrait du poids FATF erroné qui gonflait ~13 pays SEPA (PL, CZ, MT… repassent en « low »). BBAN slovaque corrigé, Raiffeisen romandes bien classées, « 89 pays » partout.

  • robustesse

    Garde anti-base-vide + durcissement entrées

    Le refresh compliance refuse de publier une base à zéro sanction (faux négatif systémique évité). BIC « XX » signalés test, IBAN géants rejetés avant calcul (anti-abus CPU).

  • cohérence

    Versions unifiées + manifeste mort supprimé

    6 versions divergentes → toutes en 1.3.0. Suppression du server.json racine vestigial (mauvais nom de package).
