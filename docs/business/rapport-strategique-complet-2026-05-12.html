1.Diagnostic chiffré du funnel cassé

Ton compteur à $0,32 n'est pas un KPI : c'est une conséquence. Voici le funnel décomposé étape par étape, avec benchmarks 2026 (Zuplo, Postman, OpenView).

Le vrai problème (ratio transaction/clé)

78 transactions / 98 clés = 0,8 transaction par clé. Le ratio sain sur les utilisateurs actifs est 50-200 transactions/clé/mois. Ça veut dire : les rares actifs font 1-2 appels test puis ne reviennent jamais. Ce n'est pas un problème de funnel d'acquisition, c'est un problème d'activation et de raison de revenir.

3 causes diagnostiquées

  • Time-to-First-Call inconnu : si le délai signup → premier curl réussi dépasse 10 minutes, la conversion est divisée par 3-4 (Postman). Tu n'as ni mesure ni curl copiable visible sur la landing après signup.
  • Aucune raison de revenir au-delà du test : un dev curieux fait un appel test, ça marche, il ne revient pas car il n'a pas de cas d'usage récurrent à plugger. Pas de webhook, pas d'alerte, pas de monitoring offert.
  • Acheteurs cibles ne signent pas via signup : les fintechs CH, éditeurs AML et trésoreries signent via RFP / recommandation / contact fondateur direct. Le funnel signup ne les capte pas. Stripe a fait ses 500 premiers clients via 1 post HN ; Plaid via 1 contact Venmo. Pas via le sign-up flow.

2.Quick wins techniques — 30 jours

7 actions à fort impact, classées par ratio impact/effort. À l'exception de #5, toutes faisables en moins d'une journée chacune.

① Curl copiable post-signup

Effort : 1 h · Impact : TTFC -50 %

Après génération de la clé sur la landing, afficher immédiatement un bloc curl pré-rempli avec la clé et un IBAN demo. Un bouton « Copier ». TTFC passe de minutes à secondes.

② Email welcome avec curl prêt à coller

Effort : 2 h · Impact : activation +30 %

Email envoyé J+0 (instant). Contient la clé, un curl prêt, un lien playground, et une phrase signée « Alain — répondez à cet email si vous êtes coincé ». Le but : ouvrir un canal de conversation.

③ Webhook « no call in 7d » → email auto

Effort : 4 h · Impact : réactivation 5-15 %

Cron quotidien. Pour chaque clé sans appel depuis 7 jours : envoyer un email avec un exemple concret de détection vIBAN scandaleux (Wise, Revolut). Pas un pitch — une démo de valeur.

④ Tier gratuit : 200 → 1000 req/mois

Effort : 30 min · Impact : friction -50 %

200 est trop pingre pour un test sérieux (sweet spot API utilitaire = 500-1000). Coût marginal nul pour toi, signal généreux pour les devs. Ça enlève l'objection « je ne peux pas vraiment tester ».

⑤ Playground public sans signup

Effort : 1 jour · Impact : top funnel +100-300 %

Un IBAN suspect pré-rempli (ex : vIBAN N26), un bouton « Valider », résultat JSON formaté avec score risque, flags AML, classification émetteur. Pas besoin de clé pour ce demo limité (3 appels par IP/jour). C'est ton meilleur SEO funnel.

⑥ Documentation interactive Swagger UI

Effort : 4-8 h · Impact : activation +30 %

Tu as déjà /openapi.json. Ajouter un mount /docs avec Swagger UI ou Stoplight Elements et un « Try it out » fonctionnel avec une clé démo en pré-rempli. Standard dev attendu en 2026.

⑦ Fix endpoint /admin/revenue

Effort : 2 h · Impact : visibilité revenu

L'endpoint utilise Basescan API V1 (deprecated). Migrer vers Etherscan API V2 (URL https://api.etherscan.io/v2/api?chainid=8453&...) ou ajouter un endpoint Stripe-Side pour avoir le cumul Stripe. Sans ça, tu navigues à vue.

Verdict quick wins

Les 7 actions ci-dessus prennent ~3-4 jours cumulés et débloquent le funnel d'activation.

Faisables en une semaine si tu y consacres 2 demi-journées. Aucune réécriture, aucun nouveau marché, aucun risque.

Logique du re-pricing

  • $9 Try = anchor bas, attire les curieux et les devs en mode test. Coût marginal négligeable.
  • $29 Pro avec badge « POPULAIRE » = effet decoy, c'est là que tu veux que 60 % des achats se concentrent (DollarPocket, 500+ SaaS analysés : +21,8 % conversion à $19 vs $25). $29 cible le sweet spot « carte perso, pas d'approval boss ».
  • $99 Scale = anchor haut, attire 10 % d'acheteurs et rend le $29 « raisonnable » par contraste.
  • 199 €/mois Swiss Premium = ton vrai produit. Bundle dédié pour fintechs/comptables CH avec facture EUR (vs USD inconfortable pour clients CH). 1 client = 2 388 €/an = équivaut à 80 packs $29.

7.Plans B / C / D — si le pivot Swiss ne décolle pas

L'option A (pivot Swiss+vIBAN décrite ci-dessus) reste la priorité. Mais voici les bifurcations possibles, classées par downside et probabilité d'activation.

Plan B — Open source partiel + freemium ouvert

  • Concept : open-sourcer la lib de validation IBAN core (mod97, BBAN parsing, country structures) sous MIT. Garder fermé : la base BIC enrichie (121k), la classification vIBAN/EMI, et le risk scoring.
  • Inspiration : OpenSanctions — open data partiel pour la presse/ONG, paid pour fintech/compliance.
  • Bénéfices : stars GitHub, traction dev, mention dans awesome-lists, crédibilité technique. Le moat (données + classification + Swiss) reste protégé.
  • Risque : invite à la fork si le repo prend de la traction. Quasi nul à 14 mois sans audience.
  • Quand activer : en parallèle de l'option A, dès maintenant. Effort 1-2 jours.

Plan C — White-label / fournisseur de données

  • Concept : arrêter de vendre directement aux fintechs, vendre uniquement aux autres éditeurs (ComplyAdvantage, Flagright, iPiD, NetGuardians) en marque blanche.
  • Modèle : $1k-$5k/mois par éditeur en redevance forfaitaire + revenue share sur leur usage. Tickets plus gros, cycle de vente plus long (3-6 mois), 1-2 deals = couvre le coût d'opportunité.
  • Bénéfices : pas de marketing, pas de support direct utilisateur, focus sur la data et l'enrichissement.
  • Risque : vendeur unique = risque concentration. Mais 2-3 deals = stable.
  • Quand activer : si Plan A ne signe pas le 1er client Swiss au 11 août, basculer dessus avec 3-5 outreach BD-to-BD (cibles #18-20 section 5).

Plan D — Exit / acqui-hire

  • Acheteurs probables : NetGuardians (CH, fraud detection), Apiax (CH, RegTech), iPiD (global VoP), ComplyAdvantage (UK, AML). Tous pourraient vouloir le module vIBAN/Swiss en interne.
  • Valorisation réaliste solo founder à $0 MRR : 30-150k CHF (acqui-hire / asset deal). Si tu as 5-10k CHF MRR : 200-600k CHF (multiple 3-5× ARR pour data B2B niche).
  • Levier : brand IBANforge.com + base BIC enrichie + classification vIBAN + 84+ mappings unique au monde + MCP server + connecteurs Pipedream/n8n.
  • Quand activer : si tu veux libérer ton temps après 18 mois (mai 2027) sans avoir abouti à 3k+ CHF MRR. Approche directe via cold pitch deck aux 4 acheteurs probables.

Mode rente passive (Plan E)

  • Concept : maintenance minimale (1-2 h/sem), refresh data auto, pas de marketing actif. Garder ouvert pour les rentes organiques.
  • Coût : ~6 $/mois infra + temps maintenance.
  • Revenu attendu : 50-200 $/mois passif (selon SEO accumulé). Pas une rente confortable, mais pas zéro.
  • Avantage : libère 8-10 h/sem pour un autre projet plus rentable. Optionnel de réactiver Plan A à un moment plus favorable (ex : 2028 si AMLR fait du bruit).
Verdict plans B/C/D/E

Ordre d'activation recommandé : A → (en parallèle) B → si échec checkpoint 90j : C → si pas de revenu mai 2027 : D ou E.

Aucun de ces plans n'est un échec. C'est une matrice de décision adaptative selon les signaux marché.
