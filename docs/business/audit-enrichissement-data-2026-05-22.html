Le diagnostic

Le socle de données est solide et déjà automatisé. L'enjeu n'est pas d'ajouter « une source SEPA » ou « OeNB » — elles sont déjà branchées. La vérification du code a évité ce piège : deux sources que la recherche recommandait sont en réalité déjà intégrées.

Le vrai gisement est en deux temps : fiabiliser trois maillons faibles, et étendre la couverture là où elle plafonne (la classification EMI).

Les 3 maillons faibles
!

Les sanctions passent par un agrégateur tiers

OFAC, EU et UN sont téléchargés depuis OpenSanctions — réputé, mais ce n'est pas la source officielle. Pour un acheteur compliance/AML, « d'où viennent vos sanctions » est une vraie question. Aggravant : les BIC sanctionnés sont extraits par expression régulière sur du texte libre — fragile. À arbitrer consciemment.

!

Les listes FATF et pays sanctionnés sont codées en dur

Ce sont des constantes dans un script. Le refresh hebdomadaire ne les met pas à jour — il ré-insère les mêmes valeurs figées. La FATF actualise 3×/an : le tableau est probablement déjà décalé. Risque concret : des indicateurs de risque faux en production, sans alerte.

!

La classification EMI / vIBAN plafonne

~85 correspondances BIC8 mappées à la main. C'est un vrai différenciateur produit, mais tout émetteur absent de la liste est classé « inconnu » — alors que le marché EMI/PI européen se compte en milliers.

Nouvelles sources à instruire

Registre EBA PSD2

JSON machine-lisible, gratuit, refresh quotidien. Étend la détection EMI/vIBAN à toute l'UE/EEE.

SWIFT IBAN Registry

Spécification officielle ISO 13616 du format IBAN par pays. Source canonique pour maintenir countries.ts.

swift.com · licence à clarifier

Banques centrales — CNB, DNB, REGAFI

Clearing tchèque (CSV), API officielles néerlandaise et française (ACPR) pour vérifier le statut d'agrément.

API officielles gratuites

SECO — sanctions suisses

CSV/XML officiels. IBANforge couvre OFAC/EU/UN mais pas la Suisse — ajout à coût faible, cohérent avec le positionnement.

seco.admin.ch
Écarté — les pièges
  • EISCD (UK) — le meilleur clearing UK, mais payant (~2 000 £/an) et accès réservé.
  • Routing Directory US (Fed) — non redistribuable ; hors périmètre IBAN.
  • Liste PEP « officielle » de personnes — elle n'existe pas. Ne pas promettre un screening PEP adossé à une source officielle gratuite.
  • EPC Directory Service (VoP) — réservé aux participants ; IBANforge utilise déjà le bon proxy public.
