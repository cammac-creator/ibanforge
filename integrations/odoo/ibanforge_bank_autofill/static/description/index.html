The problem it solves

Odoo validates the IBAN format, but it never fills the BIC or the bank name for you. The OCA base_bank_from_iban module only matches a bank if you have already created it with its national code by hand. Nobody pre-configures 121,000 banks.

IBANforge resolves the BIC and the bank name from a worldwide database in a single API call, and this module creates or reuses the matching bank record for you, with no setup.

How it works

1

Enter an IBAN

On any partner bank account, type or paste an IBAN as usual.

2

Instant lookup

IBANforge validates the IBAN and returns the BIC and bank name. An invalid IBAN shows a non-blocking warning.

3

Bank linked

The matching bank record is found or created and linked, filling the BIC and bank name automatically.

4

Never in your way

API down or no key? Entry and saving keep working exactly like stock Odoo. A bank you set by hand is never overwritten.
