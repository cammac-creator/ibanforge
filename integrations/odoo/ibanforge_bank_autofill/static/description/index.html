The problem it solves

Odoo validates the IBAN format, but it never fills the BIC or the bank name for you. The OCA base_bank_from_iban module only matches a bank if you have already created it with its national code by hand. Nobody pre-configures 121,000 BIC entries.

IBANforge resolves the BIC and the bank name from a worldwide database in a single API call, and this module creates or reuses the matching bank record for you, with no setup.

How it works

1

Enter an IBAN

On any partner bank account, type or paste an IBAN as usual.

2

Instant lookup

IBANforge validates the IBAN and returns the BIC and bank name. An invalid IBAN shows a non-blocking warning.

3

Bank linked

The matching bank record is found or created and linked, filling the BIC and bank name automatically.

4

Never in your way

API down or no key? Entry and saving keep working exactly like stock Odoo. A bank you set by hand is never overwritten.

Privacy: what leaves your Odoo server

  • Nothing, until you save an API key in Settings, IBANforge. With no key, the module makes no network call at all.
  • What is sent, once a key is saved: the IBAN typed in the Account Number field of a partner bank account (while you edit it, then again when the account is saved or its IBAN changes, imports included), and your API key in an X-API-Key header. Nothing else: no partner name, no address, no other Odoo field.
  • Where it goes: over HTTPS to https://api.ibanforge.com, or to the address you set as API Base URL. What comes back is the BIC, the bank name and the SEPA and risk indicators for that IBAN.
  • What IBANforge keeps: its privacy policy states that IBANs submitted for validation are processed in memory and are not stored. A data processing agreement is available. Each call is counted against the monthly allowance of your key.
  • What the module itself does not do: no usage statistics, no telemetry, no code downloaded, no other code run.

An IBAN can be personal data. You stay in charge of what you enter in Odoo and of whether you enable the lookup.

Free to start

A free API key allows 200 lookups a month once you give an e-mail address (25 a month without one). Get it at ibanforge.com, then paste it in Settings, IBANforge. The module itself is free and open source (AGPL-3). Need more volume? The plans are listed on ibanforge.com/pricing.

Through the form, an account makes one call while you type and one when you save it, so 200 lookups cover about 100 new accounts. Imports make one call per account.
