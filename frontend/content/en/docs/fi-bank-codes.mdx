# Finnish bank codes: what the API checks today

A Finnish IBAN is `FI`, two check digits, then a fourteen-digit BBAN whose head is the **monetary institution code**: one to four characters, allocated by Finance Finland to **banking groups**, not to individual institutions.

**Since 25 September 2026, IBANforge holds no reference data for Finnish bank codes.** Until then the API read a hand transcription of the Finance Finland list, dated 15 October 2025. Its terms of reuse were never confirmed by the publisher, and on that day we withdrew it, together with the Finnish keys of our composite bank-code map, which had been compiled from the same list. Nothing replaces them yet.

## What a Finnish answer says now

```bash
curl -X POST https://api.ibanforge.com/v1/iban/validate \
  -H "Content-Type: application/json" \
  -d '{"iban": "FI2112345600000785"}'
```

Abridged to the block this page is about:

```json
{
  "valid": true,
  "bank_code_check": {
    "value": "123",
    "status": "unavailable",
    "reason": "no_reference_data_for_country",
    "match": null,
    "register": null,
    "authoritative": false
  }
}
```

- **`valid` is still the IBAN checksum and structure**, checked as for every country.
- **`status: "unavailable"`** with **`reason: "no_reference_data_for_country"`**: we did not consult anything that could name the holder of the code. It is not a refusal, and you will never see `not_allocated` for Finland.
- **`bic` is `null`**: no BIC is derived from a Finnish bank code any more. A BIC your payee gives you can still be checked on its own with `GET /v1/bic/{code}`.

## What to do in a payment flow

Treat a Finnish IBAN like any IBAN from a country without a register: a valid checksum is a good structural sign, and the name check (VoP) at the payer's bank is what confirms the account. Do not stop a payment because the bank code is unverified: the answer says we did not look, not that the code is wrong.

## The honest limits

- **No bank-code verdict for Finland** until a list whose reuse we can establish is read again.
- **We never check the account or its holder.** That was already true with the list.
- **Prefix length still matters** if you read Finnish codes yourself: the code is the longest allocated prefix, one to four characters, not a fixed slice.
