# Finnische Bankcodes: was die API heute prüft

Eine finnische IBAN besteht aus `FI`, zwei Prüfziffern und einer vierzehnstelligen BBAN, an deren Anfang der **Code des monetären Instituts** steht: ein bis vier Zeichen, von Finance Finland an **Bankengruppen** vergeben, nicht an einzelne Institute.

**Seit dem 25. September 2026 hält IBANforge keine Referenzdaten für finnische Bankcodes.** Bis dahin las die API eine Abschrift der Liste von Finance Finland mit Stand 15. Oktober 2025. Ihre Weiterverwendungsbedingungen hat der Herausgeber nie bestätigt, und wir haben sie an diesem Tag zurückgezogen, zusammen mit den finnischen Schlüsseln unserer zusammengesetzten Bankcode-Karte, die aus derselben Liste stammten. Noch ersetzt sie nichts.

## Was eine finnische Antwort jetzt sagt

```bash
curl -X POST https://api.ibanforge.com/v1/iban/validate \
  -H "Content-Type: application/json" \
  -d '{"iban": "FI2112345600000785"}'
```

Gekürzt auf den Block, um den es hier geht:

```json
{
  "valid": true,
  "bank_code_check": {
    "value": "123",
    "status": "unavailable",
    "reason": "no_reference_data_for_country",
    "match": null,
    "register": null,
    "authoritative": false
  }
}
```

- **`valid` bleibt die Prüfsumme und der Aufbau der IBAN**, geprüft wie für jedes Land.
- **`status: "unavailable"`** mit **`reason: "no_reference_data_for_country"`**: Wir haben nichts konsultiert, das den Inhaber des Codes nennen könnte. Das ist keine Ablehnung, und `not_allocated` sehen Sie für Finnland nie.
- **`bic` ist `null`**: Aus einem finnischen Bankcode wird kein BIC mehr abgeleitet. Einen BIC, den Ihr Zahlungsempfänger Ihnen nennt, können Sie weiterhin einzeln mit `GET /v1/bic/{code}` prüfen.

## Was in einem Zahlungsablauf zu tun ist

Behandeln Sie eine finnische IBAN wie die eines Landes ohne Register: Eine gültige Prüfsumme ist ein gutes Zeichen für den Aufbau, und die Namensprüfung (VoP) bei der Bank des Zahlers bestätigt das Konto. Stoppen Sie keine Zahlung, weil der Bankcode nicht geprüft ist: Die Antwort sagt, dass wir nicht nachgesehen haben, nicht, dass der Code falsch ist.

## Die ehrlichen Grenzen

- **Kein Urteil über finnische Bankcodes**, bis eine Liste erneut gelesen wird, deren Weiterverwendung wir belegen können.
- **Wir prüfen nie das Konto oder seinen Inhaber.** Das galt schon mit der Liste.
- **Die Präfixlänge zählt weiterhin**, wenn Sie finnische Codes selbst lesen: Der Code ist das längste vergebene Präfix, ein bis vier Zeichen, keine feste Stelle.
