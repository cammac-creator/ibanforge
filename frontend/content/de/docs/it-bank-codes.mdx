# Italienische Bankleitzahlen: die Register der Banca d'Italia

Eine italienische IBAN trägt den **ABI-Code** an den Stellen 6 bis 10, nach dem CIN-Buchstaben und vor dem fünfstelligen CAB. Die Banca d'Italia veröffentlicht als Open Data unter CC BY 4.0 die Register der Banken, Zahlungsinstitute und E-Geld-Institute, die sie beaufsichtigt, **mit ihrer Geschichte**: wann jedes eingetragen wurde, wann es gelöscht wurde, und die Verschmelzungen und Eingliederungen, die es übernommen haben.

IBANforge liest beide jede Woche neu und antwortet dreierlei.

## Ein gültiger Code: der Inhaber, benannt von der Banca d'Italia

```bash
curl -X POST https://api.ibanforge.com/v1/iban/validate \
  -H "Content-Type: application/json" \
  -d '{"iban": "IT86W0306901600000000123456"}'
```

```json
{
  "valid": true,
  "bank_code_holder": "confirmed",
  "bank_code_check": {
    "value": "03069",
    "status": "verified",
    "match": "register",
    "register": "Banca d'Italia, registers of banks, payment institutions and e-money institutions (…)",
    "authoritative": false,
    "institution": {
      "name": "INTESA SANPAOLO S.P.A.",
      "street": "PIAZZA SAN CARLO, 156",
      "post_code": "10121",
      "town": "TORINO",
      "country": "IT",
      "lei": "2W8N8UU78PMDQKZENC08"
    },
    "as_of": "2026-09"
  }
}
```

Der Name wird so geliefert, wie das Register ihn schreibt. Das Register veröffentlicht keinen BIC: Der `bic`-Block neben dem Urteil kommt weiterhin aus unserer zusammengesetzten Karte (`basis: "curated_map"`).

## Ein Code, den die Banca d'Italia gelöscht hat: zurückgezogen, mit Rechtsnachfolger, nie abgelehnt

```json
{
  "valid": true,
  "bank_code_holder": "inferred",
  "bic": null,
  "bank_code_check": {
    "value": "03111",
    "status": "verified",
    "match": "register",
    "authoritative": false,
    "retired": true,
    "retired_on": "2021-04-11",
    "superseded_by": "03069",
    "institution": {
      "name": "UNIONE DI BANCHE ITALIANE SOCIETA' PER AZIONI (IN FORMA ABBREVIATA UBI BANCA)",
      "street": null,
      "post_code": null,
      "town": null,
      "country": "IT"
    }
  },
  "next_steps": [{ "code": "bank_code_retired", "do": "Update the beneficiary details before sending. …" }]
}
```

Bis zum 25. September 2026 antwortete dieser Code „Banca Carige“: die falsche Bank, die selbst 2022 übernommen wurde. Die neue Antwort liest sich so:

- `retired: true` und `retired_on`: der letzte Tag, an dem das Register den Code für seinen letzten Inhaber führt.
- `superseded_by`: der **Rechtsnachfolger** durch Verschmelzung oder Eingliederung, verfolgt bis zu einer heute gültigen Bank (UBI Banca, dann Intesa Sanpaolo). Das ist nicht unbedingt die Bank, die das Konto führt: UBI hatte vor ihrer Übernahme Filialen an BPER abgegeben. Eine Übertragung von Aktiva (die Abwicklung der Banca Popolare di Vicenza 2017, zum Beispiel) schafft keinen Rechtsnachfolger, und keiner wird genannt.
- `bank_code_holder: "inferred"`: Heute hält niemand diesen Code, daher ist `checks.bank_code` `inferred`, nicht `pass`. Ein deutscher Code, den die Bundesbank zurückzieht, bleibt `confirmed`, weil er noch in ihrer gültigen Datei steht.
- Kein BIC: Der BIC, den unsere Karte lieferte, gehörte einer Bank, die den Code nicht mehr hält.
- **Nie eine Ablehnung**: Wie lange eine alte IBAN nach einer italienischen Fusion erreichbar bleibt, wird nirgends veröffentlicht. Fragen Sie den Empfänger nach seinen aktuellen Angaben.

Das offizielle italienische Beispiel des ISO-13616-Registers, `IT60 X054 2811 1010 0000 0123 456`, ist einer dieser Codes: ABI 05428, Banca Popolare di Bergamo, 2017 von UBI Banca übernommen, die selbst 2021 von Intesa Sanpaolo übernommen wurde.

## Ein Code, den die Register nicht führen: die bisherige Antwort, nie „nicht vergeben“

Die Banca d'Italia führt die Institute, die sie einträgt, nicht die Vergabe des ABI-Coderaums. **Poste Italiane (07601)**, die **Banca d'Italia selbst (01000)** und die italienischen Zweigniederlassungen europäischer Zahlungsinstitute (**Qonto, 36092**) geben echte italienische IBAN außerhalb dieser Register aus. Ein italienischer Code, den die Register nicht führen, erhält daher genau die bisherige Antwort: unsere zusammengesetzte Karte, `authoritative: false`, und nie `not_allocated`.

## Was die Register veröffentlichen

| Feld | In den Registern | Hinweis |
|---|---|---|
| `name` | ja | so, wie die Banca d'Italia ihn schreibt |
| `street` / `post_code` / `town` | ja | der Sitz in Italien; bei einer ausländischen Bank ihre italienische Zweigniederlassung |
| `lei` | die meisten gültigen Codes | |
| `bic` | nein | der `bic`-Block bleibt der unserer zusammengesetzten Karte |
| Löschung, Datum, Rechtsnachfolger | ja | aus der Geschichte und der Liste der Verschmelzungen und Eingliederungen |

Gefiltert wird nach **Register** (Banken, Zahlungsinstitute, E-Geld-Institute), nie nach Codebereich: Zahlungsinstitute tragen Codes 19xxx, und die übrigen Register (Vermögensverwalter, Finanzintermediäre) nennen Gesellschaften, die keine IBAN ausgeben.

## Aktualität und Quellenangabe

Die Register werden **jede Woche** neu gelesen, und `as_of` ist die Ausgabe: das Datum der Datei, die die Banca d'Italia veröffentlicht. Die Daten sind Open Data unter **CC BY 4.0**, das die gewerbliche Weiterverwendung erlaubt, sofern die Quelle genannt und die Änderungen angegeben werden. Jede Antwort, die sie nutzt, trägt die Quellenangabe in `bank_code_check.register`: *Banca d'Italia, Albi ed elenchi di vigilanza, CC BY 4.0, normalised and joined by IBANforge* (Codes auf fünf Ziffern ergänzt, gültige Codes ausgewählt, gelöschte Codes datiert und mit ihrem Rechtsnachfolger verbunden). Siehe [Datenquellen](/docs/data-sources).

## Die ehrlichen Grenzen

- **Wir prüfen den ABI-Code, nie das Konto oder seinen Inhaber.**
- **Ein Fehlen ist keine Ablehnung**, und ein gelöschter Code auch nicht.
- **Der Rechtsnachfolger ist keine Routing-Anweisung.** Fragen Sie den Empfänger.
- **Institut, nicht Filiale.** Der CAB bezeichnet eine Filiale; wir lehnen nie auf ihm ab.
