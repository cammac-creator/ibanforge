# IBANforge API

[Postman Collection herunterladen](/ibanforge-postman.json)

IBANforge ist eine schnelle, zuverlässige API für **IBAN-Validierung** und **BIC/SWIFT-Abfrage**. Sie deckt 89 Länder ab und bietet Echtzeit-Prüfsummenverifizierung, BBAN-Strukturanalyse, angereicherte Institutsdaten von GLEIF und weiteren öffentlichen Quellen (SWIFT-Verzeichnis, Bundesbank, SIX, NBP), **SEPA-Konformitätsinformationen**, **Emittentenklassifizierung** (Bank vs. E-Geld-Institut/Neobank), **Sanktions- und Compliance-Screening** mit Risiko-Score von 0–100 sowie exklusive **Schweizer Clearing-Daten (BC-Nummer)** aus dem SIX BankMaster.

> **Kostenlos starten, ganz ohne Schlüssel.** Zwei Endpoints lösen ein ganzes Problem gratis: [`/v1/reference/validate`](/docs/swiss-qr-iban) prüft Zahlungsreferenzen (RF/ISO 11649, Schweizer QRR, belgische OGM, finnische viitenumero) mit belegtem Verdikt, und [`/v1/address/check`](/docs/structured-addresses) prüft eine strukturierte ISO-20022-Adresse gegen die SPS-, T2- oder Fedwire-Regeln vor den Umstellungen im November 2026.

## Basis-URL

```
https://api.ibanforge.com
```

Alle Endpunkte werden über HTTPS bereitgestellt. HTTP-Anfragen werden automatisch umgeleitet.

## Authentifizierung

Drei Wege hinein — wählen Sie, was passt; Ihre App oder Ihr Agent landet nie in einer Sackgasse:

1. **Kostenloser API-Schlüssel** — 200 Anfragen/Monat, keine Kreditkarte. [Generieren Sie einen](/docs/api-keys) mit einem einzigen POST und senden Sie dann `Authorization: Bearer ifk_...` mit jeder Anfrage.
2. **Prepaid-Guthabenpakete** — 1k = 5 $, 5k = 20 $, 25k = 80 $. Sie verfallen nie und sind **per Karte** oder in USDC kaufbar (`POST /v1/credits/buy/1k|5k|25k`). Siehe [Preise](/pricing).
3. **x402-Mikrozahlungen** — vollständig autonome Bezahlung pro Aufruf in USDC für Agenten, ganz ohne Konto. Siehe [x402-Leitfaden](/docs/x402).

Eine Anfrage ohne gültigen Schlüssel oder Zahlung erhält eine `402`-Antwort mit maschinenlesbaren Anweisungen für alle drei Wege — autonome Agenten können sich selbst onboarden.

## Endpunkte im Überblick

| Endpunkt | Methode | Kosten | Beschreibung |
|---|---|---|---|
| `/v1/iban/validate` | POST | $0.005 | Einzelne IBAN validieren |
| `/v1/iban/batch` | POST | $0.002/IBAN | Bis zu 100 IBANs validieren |
| `/v1/bic/:code` | GET | $0.003 | BIC/SWIFT-Code abfragen |
| `/v1/iban/compliance` | POST | $0.02 | Sanktionen, FATF, SEPA/VoP-Erreichbarkeit + Risiko-Score 0–100 |
| `/v1/ch/clearing/:iid` | GET | $0.003 | Schweizer BC-Nummer / IID abfragen (SIX BankMaster) |
| `/v1/reference/validate` | GET/POST | Kostenlos | Prufziffer von Zahlungsreferenzen (RF/ISO 11649, Schweizer QRR, belgische OGM, finnische viitenumero) |
| `/v1/address/check` | POST | Kostenlos | ISO-20022-Adresskonformität (SPS, HVPS+/T2, Fedwire), jeder Befund mit Quelle |
| `/v1/demo` | GET | Kostenlos | Beispielvalidierungen (keine Zahlung erforderlich) |
| `/health` | GET | Kostenlos | Service-Gesundheitsprüfung |

## Schnellbeispiel

```bash
curl -X POST https://api.ibanforge.com/v1/iban/validate \
  -H "Content-Type: application/json" \
  -d '{"iban": "CH10 0023 0000 0000 1234 5"}'
```

## Kostenloses Testen

Verwenden Sie den Endpunkt `/v1/demo`, um die API ohne Zahlungseinrichtung zu testen:

```bash
curl https://api.ibanforge.com/v1/demo
```

Dieser gibt vorvalidierte Beispiel-IBANs aus mehreren Ländern zurück, damit Sie das Antwortformat erkunden können.
