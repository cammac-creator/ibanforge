# Codes banque finlandais : ce que l'API contrôle aujourd'hui

Un IBAN finlandais, c'est `FI`, deux chiffres de clé, puis un BBAN de quatorze chiffres qui commence par le **code d'établissement monétaire** : un à quatre caractères, attribués par Finance Finland à des **groupes bancaires**, pas à des établissements individuels.

**Depuis le 25 septembre 2026, IBANforge ne détient aucune donnée de référence pour les codes banque finlandais.** Jusque-là, l'API lisait une transcription à la main de la liste de Finance Finland, datée du 15 octobre 2025. Ses conditions de réutilisation n'ont jamais été confirmées par l'éditeur, et nous l'avons retirée ce jour-là, avec les clés finlandaises de notre carte composite, compilées à partir de la même liste. Rien ne les remplace pour l'instant.

## Ce que dit maintenant une réponse finlandaise

```bash
curl -X POST https://api.ibanforge.com/v1/iban/validate \
  -H "Content-Type: application/json" \
  -d '{"iban": "FI2112345600000785"}'
```

Réduite au bloc dont parle cette page :

```json
{
  "valid": true,
  "bank_code_check": {
    "value": "123",
    "status": "unavailable",
    "reason": "no_reference_data_for_country",
    "match": null,
    "register": null,
    "authoritative": false
  }
}
```

- **`valid` reste la clé et la structure de l'IBAN**, contrôlées comme pour tout pays.
- **`status: "unavailable"`** avec **`reason: "no_reference_data_for_country"`** : nous n'avons rien consulté qui puisse nommer le titulaire du code. Ce n'est pas un refus, et vous ne verrez jamais `not_allocated` pour la Finlande.
- **`bic` vaut `null`** : aucun BIC n'est plus déduit d'un code banque finlandais. Un BIC que votre bénéficiaire vous donne se contrôle toujours seul avec `GET /v1/bic/{code}`.

## Que faire dans un flux de paiement

Traitez un IBAN finlandais comme celui de tout pays sans registre : une clé valide est un bon signe de structure, et la vérification du nom (VoP) à la banque du payeur est ce qui confirme le compte. N'arrêtez pas un paiement parce que le code banque n'est pas vérifié : la réponse dit que nous n'avons pas regardé, pas que le code est faux.

## Les limites honnêtes

- **Aucun verdict sur le code banque pour la Finlande**, jusqu'à la relecture d'une liste dont nous pourrons établir la réutilisation.
- **Nous ne contrôlons jamais le compte ni son titulaire.** C'était déjà vrai avec la liste.
- **La longueur du préfixe compte toujours** si vous lisez vous-même les codes finlandais : le code est le plus long préfixe attribué, d'un à quatre caractères, pas une tranche fixe.
