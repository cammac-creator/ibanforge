# API IBANforge

[Telecharger la collection Postman](/ibanforge-postman.json)

IBANforge est une API rapide et fiable pour la **validation IBAN** et la **recherche BIC/SWIFT**. Elle couvre 89 pays avec vérification de checksum en temps réel, analyse de la structure BBAN, données institutionnelles enrichies via GLEIF et autres sources publiques (annuaire SWIFT, Bundesbank, SIX, NBP), **informations de conformité SEPA**, **classification de l'émetteur** (banque vs. EMI/néobanque), **screening sanctions & conformité** avec score de risque 0–100, et les données exclusives de **clearing suisse (BC-Nummer)** issues du SIX BankMaster.

> **Commencez ici.** La [prise en main](/docs/onboarding) parcourt tout le chemin en dix minutes — l'appel sans clé, la clé gratuite, chaque bloc de la réponse lu par son vrai nom, un lot de 100 et les deux sortes d'erreur. Chaque `curl` de cette page a réellement été exécuté, et chaque réponse est celle que l'API a rendue.

> **Commencez gratuitement, sans même une clé.** Deux endpoints règlent un problème entier sans rien payer : [`/v1/reference/validate`](/docs/swiss-qr-iban) contrôle les références de paiement (RF/ISO 11649, QRR suisse, OGM belge, viitenumero finlandais) avec un verdict sourcé, et [`/v1/address/check`](/docs/structured-addresses) contrôle une adresse ISO 20022 structurée contre les règles SPS, T2 ou Fedwire avant les échéances de novembre 2026.

## URL de base

```
https://api.ibanforge.com
```

Tous les endpoints sont servis en HTTPS. Les requetes HTTP sont automatiquement redirigees.

## Authentification

**Avant toutes les trois : les premiers appels de la semaine ne demandent rien.** `POST /v1/iban/validate` avec un vrai `iban` et sans clé est servi en entier, 25 fois par semaine pour l'adresse d'où il vient (semaine ISO en UTC, remise à zéro le lundi à 00:00 UTC). La réponse porte un bloc `trial` qui dit combien il en reste cette semaine, quand le décompte repart, et la requête unique qui donne une clé gratuite. C'est une dégustation, pas un palier : au-delà de 25 dans la semaine, l'endpoint répond de nouveau `402`, avec `cause.reason: "trial_exhausted"`.

Ensuite, trois portes d'entrée — choisissez ce qui vous convient, votre app ou votre agent ne tombe jamais sur un cul-de-sac :

1. **Clé API gratuite** — 25 requêtes/mois sans e-mail. [Générez-la](/docs/api-keys) avec un POST sans corps, puis envoyez `Authorization: Bearer ifk_...`. Réclamer cette même clé avec un code reçu par e-mail porte le quota à 200/mois, sans carte.
2. **Packs de crédits prépayés** — 1k = 4 $, 5k = 20 $, 25k = 80 $. Ils n'expirent jamais, achetables **par carte** ou en USDC (`POST /v1/credits/buy/1k|5k|25k`). Voir les [tarifs](/pricing).
3. **Micropaiements x402** — paiement à l'appel entièrement autonome en USDC pour les agents, sans aucun compte. Voir le [guide x402](/docs/x402).

Une requête sans clé valide ni paiement reçoit une réponse `402` avec des instructions lisibles par machine pour les trois voies — les agents autonomes s'auto-embarquent.

## Endpoints en un coup d'oeil

| Endpoint | Methode | Cout | Description |
|---|---|---|---|
| `/v1/iban/validate` | POST | $0.005 | Valider un IBAN unique |
| `/v1/iban/batch` | POST | $0.002/IBAN | Valider jusqu'a 100 IBAN |
| `/v1/bic/:code` | GET | $0.003 | Rechercher un code BIC/SWIFT |
| `/v1/iban/compliance` | POST | $0.02 | Sanctions, FATF, joignabilité SEPA/VoP + score de risque 0–100 |
| `/v1/ch/clearing/:iid` | GET | $0.003 | Recherche BC-Nummer / IID suisse (SIX BankMaster) |
| `/v1/iban/format` | GET ou POST | Gratuit | Structure, clé de contrôle, pays et BBAN, sans clé. Le registre (BIC, banque, SEPA, sanctions, clearing suisse) est ce que les appels payants ajoutent |
| `/v1/reference/validate` | GET/POST | Gratuit | Checksum de reference de paiement (RF/ISO 11649, QRR suisse, OGM belge, viitenumero finlandais) |
| `/v1/address/check` | POST | Gratuit | Conformité d'adresse postale ISO 20022 (SPS, HVPS+/T2, Fedwire), chaque constat sourcé |
| `/v1/ch/qr-bill/check` | POST | Gratuit | Charge utile de QR-facture suisse : en-tête, appariement QR-IBAN et référence, sommes de contrôle, adresse structurée (S) ou combinée (K) avant le 14.11.2026, avec une forme structurée proposée |
| `/v1/audit/upload` | POST | Aperçu gratuit, puis 149 $ | Un fichier de créanciers entier (CSV ou XLSX) : chaque ligne contre les mêmes registres, doublons, contrôles BIC et adresse ; aperçu masqué gratuit, classeur annoté après paiement. La page pour non-développeurs est [/audit](/audit) |
| `/v1/demo` | GET | Gratuit | Exemples de validation (sans paiement) |
| `/health` | GET | Gratuit | Verification de l'etat du service |

## Exemple rapide

Sans clé, sans inscription — cet appel fonctionne tel quel, 25 fois par semaine pour l'adresse d'où il vient :

```bash
curl -X POST https://api.ibanforge.com/v1/iban/validate \
  -H "Content-Type: application/json" \
  -d '{"iban": "CH10 0023 0000 0000 1234 5"}'
```

La réponse porte alors un bloc `trial` supplémentaire :

```json
"trial": {
  "calls_used_this_week": 1,
  "calls_left_this_week": 24,
  "weekly_limit": 25,
  "resets": "Monday 00:00 UTC",
  "resets_at": "2026-09-28T00:00:00Z",
  "free_key": "POST https://api.ibanforge.com/v1/keys/generate with {\"source\":\"api-trial\"} — no e-mail, no card, nothing to confirm: it returns an ifk_ key that works on every endpoint, good for 200 requests a month once claimed (POST /v1/keys/claim, key in the Authorization header, with a code mailed to an address you read). Unclaimed, the key starts at 25 requests a month",
  "docs": "https://ibanforge.com/docs/api-keys?src=api-trial"
}
```

Au-delà des 25 appels de la semaine, prenez la [clé gratuite](/docs/api-keys) — un seul POST, sans carte — et ajoutez `Authorization: Bearer ifk_...` à la même requête.

## Test gratuit

Utilisez le endpoint `/v1/demo` pour tester l'API sans configuration de paiement :

```bash
curl https://api.ibanforge.com/v1/demo
```

Cela renvoie des exemples d'IBAN pre-valides de plusieurs pays afin que vous puissiez explorer le format de reponse.
