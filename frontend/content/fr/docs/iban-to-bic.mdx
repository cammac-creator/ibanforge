# IBAN vers BIC

Le BIC ne se calcule pas à partir des chiffres de contrôle de l’IBAN. IBANforge extrait un code bancaire selon la structure du pays et recherche une correspondance dans ses références. **Le résultat dépend de la source et de sa couverture.** Il ne confirme ni l’existence du compte ni son titulaire.

Documentation revue le 4 novembre 2026. Si vous possédez déjà le BIC, utilisez plutôt [la recherche BIC](/fr/docs/bic-lookup).

## Essayer une validation unitaire

Cet IBAN est un exemple de documentation, jamais une instruction de paiement. L’appel bénéficie de l’essai REST sans clé dans la limite disponible ; voir [la prise en main](/fr/docs/onboarding). Pour un usage suivi, [conservez votre clé API](/fr/docs/api-keys) et transmettez-la dans `X-API-Key`.

```bash
curl --silent --show-error --fail-with-body --max-time 20 \
  'https://api.ibanforge.com/v1/iban/validate' \
  -H 'Content-Type: application/json' \
  -d '{"iban":"DE89370400440532013000"}'
```

Lisez la réponse complète, notamment `valid`, `bic`, `bank_code_check` et `checks`. Un résultat `valid: true` ne garantit pas un bloc `bic`, et ne permet pas de conclure que le compte existe. Le [contrat de validation](/fr/docs/iban-validate) détaille les contrôles et leurs états.

## Quelle source relie le code banque au BIC ?

| `bic.basis` | Ce qui a répondu |
|---|---|
| `national_register` | Le registre du pays publie la correspondance. Lire aussi `bic.authoritative`, les dates et les éventuelles réserves. |
| `curated_map` | La carte maintenue par IBANforge contient la correspondance ; ce n’est pas un registre d’attribution. |
| `directory_prefix` | Une recherche par préfixe a proposé une correspondance. `bank_code_check.candidates` indique l’ambiguïté lorsqu’il est présent. |

`bic.code` conserve la forme à 8 ou 11 caractères publiée par la source. `bic.bic8` facilite une comparaison au niveau du préfixe, mais **deux BIC11 différents peuvent partager le même BIC8** : cette égalité ne suffit pas à confirmer la même banque locale. Ne tronquez pas une référence d’agence et n’ajoutez pas une agence supposée pour remplir un champ obligatoire.

`bic.source` nomme la référence, `bic.as_of` date le rafraîchissement du jeu consulté et `bic.source_as_of`, lorsqu’il existe, date le contenu d’une copie figée. Une importation récente ne rajeunit pas cette copie. Les [sources des données](/fr/docs/data-sources) décrivent les registres et leurs limites sans supposer une cadence uniforme.

## Réponse absente, indisponible ou historique

| Indication | Traitement à prévoir |
|---|---|
| `bic: null` ou bloc absent | Aucune référence BIC exploitable dans cette réponse. Ne pas en fabriquer une. |
| `bank_code_check.status: verified` | Lire le registre, `authoritative` et les réserves : cet état nomme un établissement, pas le titulaire du compte. |
| `reason: not_allocated` avec `authoritative: true` | Le registre consulté nie l’attribution du code bancaire. Faire corriger la donnée à la source. |
| `absent_from_reference_data`, `no_reference_data_for_country`, `register_names_no_holder` | Absence ou limite des références, pas preuve universelle d’un code inexistant. |
| `national_register_unavailable`, `lookup_failed` | La référence attendue n’a pas pu être consultée ; ne pas transformer l’incident en refus bancaire. |
| `retired`, `superseded_by` ou `bic.redirected_from` | Lire la portée historique ou la redirection indiquée ; conserver l’original et proposer une revue, sans réécrire l’IBAN. |

`bic.authoritative` concerne la correspondance avec le BIC ; `bank_code_check.authoritative` concerne le verdict sur le code bancaire. Ne les fusionnez pas en un seul « paiement autorisé ». `not_in_register` se lit avec sa raison et sa source, jamais seul.

## Intégrer le résultat dans une reprise de données

Conservez l’IBAN et le BIC fournis, puis ajoutez le résultat et sa provenance à côté. Un écart, plusieurs candidats ou une information manquante restent à examiner. Le [guide de revue fournisseurs](/fr/blog/2026-09-02-missing-bank-details-before-an-erp-migration) et les [recettes](/fr/docs/recipes) montrent ce parcours ; la [validation par lot](/fr/docs/iban-batch) convient à plusieurs IBAN.

L’adresse d’un établissement n’est pas celle du bénéficiaire. Le [registre VoP](/fr/docs/vop) ne renvoie pas non plus une correspondance entre un nom et un compte. Confirmez séparément les coordonnées nécessaires au circuit de paiement choisi.
